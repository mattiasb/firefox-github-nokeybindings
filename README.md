# GitHub Nokeys

Firefox extension that disables <https://github.com> keybindings.

## Development

1. Write code.
2. Run `make` to package the extension.
3. Install the extension temporarily:
   1. Go to <about:debugging#/runtime/this-firefox>.
   2. Press `Load Temporary Add-on`.
   3. Open `dist/github-nokeys.xpi`.
4. Submit at <https://addons.mozilla.org/en-US/developers/addons>!
